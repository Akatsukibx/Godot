# Godot

ราตรีเวียงหมอก (Ratree Wiangmok): a single-player prototype built with Godot 4.7.2 (.NET / C#).

## Running the game

1. Install the [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0).
2. Download Godot 4.7.2 **.NET** for Windows and put its files in `engine/`, so the editor sits at `engine/Godot.exe`. The `engine/` folder is not in this repo.
3. Double-click `เล่นเกม.bat`, or open `game/project.godot` in Godot.

The game code is in `game/scripts/`, the game data is in `game/data/`, and the scenes are in `game/models/` and `game/scenes/`.
